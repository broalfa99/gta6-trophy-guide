Offline guide and tracker for all 55 Grand Theft Auto VI PlayStation 5 trophies: a searchable checklist with saved progress, export and import, kind and grade filters, a spoiler setting, a four-stage roadmap to the platinum, missable flags, and an own-word guide with a cited source for every trophy.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
